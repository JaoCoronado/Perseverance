# Perseverance Rover 3D Simulation

En este proyecto te ayudaré a crear una simulación en 3D del rover Perseverance de la NASA en Marte, usando Three.js y Vite: un terreno marciano, el rover construido con primitivas, conducción con teclado y detalles visuales como polvo, sombras y un HUD.

Today's goal: build a 3D simulation of the NASA Perseverance rover on Mars in a 60-minute class, while practicing Claude Code commands and workflows from the Platzi course.

## Stack

- Three.js (WebGL) in a single-page web app
- Vite for the dev server
- Plain JavaScript (ES modules)

## Class Plan (60 minutes)

| Time | Step | Outcome |
|------|------|---------|
| 0-5 min | Setup | Project scaffold with Vite and Three.js, dev server running |
| 5-15 min | Mars scene | Terrain, reddish sky, lighting, camera and orbit controls |
| 15-30 min | Rover model | Chassis, six wheels, rocker-bogie suspension, mast, camera head, robotic arm built from primitives |
| 30-42 min | Movement | Keyboard driving (WASD), wheel rotation, suspension tilt on uneven terrain |
| 42-52 min | Polish | Dust particles, shadows, HUD with speed and position, follow camera |
| 52-60 min | Review | Run the app, review the code with Claude Code, wrap up and next steps |

## Working Agreements

- Keep the code simple and readable; one module per concern (scene, rover, controls, hud).
- Commit in small steps using conventional commits.
- Verify each step in the browser before moving on.
